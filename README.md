# python-docx-project

This project is designed to create, read, and manipulate Word documents using the `python-docx` library.

## What to Replace 
- Company Names
- Financials 
- Dates
- Names - first and last if applicable 
- Market Reference 
- Phone Numbers
- Addresses

## Installation

To install the required dependencies, run the following command:

```
pip install -r requirements.txt
```

## Usage

To run the application, execute the following command:

```
python src/main.py
```

Create a spool directory in project base directory 

mkdir -p spool 

Place .docx file to process in spool/input 

## Features

- Create new Word documents
- Add paragraphs and text to documents
- Save and read existing documents

## Example

Here is a simple example of how to use the application:

1. Run the application.
2. Follow the prompts to create or manipulate a Word document.
